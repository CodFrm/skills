# 飞书装修项目管理

用飞书多维表格、文档和云盘维护住宅装修项目，覆盖预算与采购、施工进度、设备入户、分阶段验收、增减项、结算和资料归档，并可把已投入使用的设备同步到资产台账。

## 安装

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/feishu-life/feishu-renovation-manager
```

## 依赖

- 可访问飞书多维表格的智能体运行环境；使用总览和归档能力时还需要飞书文档与云盘访问能力。
- 用户对目标 Base、文档和资料目录的最小必要权限。
- 合同、报价、图纸、付款或现场材料仅在用户授权的任务范围内使用。

## 初始化

在运行时提供装修主 Base 入口，并按需提供总览文档、设计资料、合同资料和资产 Base 入口。Skill 会先读取真实数据表、字段、视图及相关材料，将信息区分为已确认、待确认、暂估和冲突，再更新对应台账并回读。新建项目结构前，应先让用户确认表与字段方案。

`examples/` 中的项目状态明确为虚构，`templates/` 仅提供不含真实凭据的通用配置占位符。

## 隐私边界

飞书入口及其凭据、数据表和记录标识、账号与本地配置不得写入仓库。住宅、身份、联系方式、合同、订单、报价和付款凭证等材料只应保留在用户授权的数据源中，摘要遵循最小披露。删除文件或记录、联系商家、确认报价或付款等动作必须先取得明确授权。
