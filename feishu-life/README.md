# 飞书生活管理 Skills

这组 Skills 用飞书承载个人或家庭生活项目的数据：资产台账负责资产从购入到退役的生命周期，装修管理负责预算、采购、施工、验收、结算和资料归档。两者可以独立安装，也可以在设备投入使用后联动。

## 包含内容

- [个人资产台账](./feishu-personal-asset-ledger/)：录入和维护耐用品资产、状态、保修与使用成本。
- [装修项目管理](./feishu-renovation-manager/)：管理装修预算、采购、施工进度、设备入户、验收与结算。

## 安装

将需要的仓库链接交给支持安装 Skills 的智能体。例如：

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/feishu-life/feishu-personal-asset-ledger
```

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/feishu-life/feishu-renovation-manager
```

## 依赖与初始化

- 需要可访问飞书多维表格的智能体运行环境，以及用户授予的最小必要权限；装修管理还可能使用飞书文档和云盘。
- 接管现有数据时，在运行时提供相应飞书入口，Skill 会先读取真实表结构和字段，再执行写入。
- 新建台账时，应由用户明确提出创建请求；确认字段或表结构后，先写入少量虚构示例或首批已确认数据并回读验证。

## 隐私边界

仓库只保存通用流程、字段模板和明确标注的虚构示例。飞书入口及其凭据、数据表和记录标识、账号信息，以及个人、订单、合同、住宅和财务数据只应在获授权的运行时使用，不应写入仓库、模板、日志或普通摘要。运行时也应遵循最小披露、写后回读，以及删除和对外动作先确认的原则。
