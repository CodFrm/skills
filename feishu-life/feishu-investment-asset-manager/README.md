# 飞书投资资产管家

用飞书多维表格统一管理股票、黄金、基金、ETF、可转债、现金理财等投资资产，维护持仓、交易、估值、总利润、做 T 收益和资产配置仪表盘。

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/feishu-life/feishu-investment-asset-manager
```

## 主要能力

- 从交割单、持仓截图和订单中提取交易数据，核对成交金额、费用及实际到账。
- 使用真实买入成本统计浮动盈亏、已实现盈亏、分红、利息与账户总利润。
- 配对先买后卖或先卖后买交易，按实际费用统计单次、当日、当月和累计做 T 收益。
- 管理 A 股、港股、美股、基金、ETF、可转债及多币种资产。
- 区分实物黄金、首饰金、积存金、纸黄金和黄金 ETF，处理纯度、重量、工费、溢价与回购估值。
- 混合资产统一按人民币市值制作资产配置图，不把股票股数、黄金克数和基金份额直接相加。
- 写入前读取飞书真实结构并查重，写入后按记录或仪表盘组件回读验证。

## 飞书数据建议

推荐维护“资产持仓”“交易流水”“做T收益”三张核心表；需要历史趋势时再增加“价格快照”。接管现有 Base 时必须先读取真实字段，不按模板覆盖用户已有结构。

## 隐私与安全

- 不保存账户号、股东号、银行卡号、订单号、验证码、Cookie、资金密码或私钥。
- 不登录券商或银行，不自动交易、申购、赎回或转账。
- 缺少历史成本、当前价格、汇率或配对交易时保留空值，不虚构利润。
- 做 T 收益是已实现收益的策略归因，不能再次叠加到账户总利润中。
- 最新价格、汇率和产品规则需要在运行时核验并注明时间与来源。

仅作资产记录与信息分析，不构成投资建议。
