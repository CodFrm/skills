# 飞书个人资产台账

用飞书多维表格建立和维护个人或家庭耐用品台账，覆盖订单或资料录入、查重、状态变化、保修、使用成本、退役出售，以及与装修或集中采购项目的联动。

## 安装

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/feishu-life/feishu-personal-asset-ledger
```

## 依赖

- 可访问飞书 Base / 多维表格的智能体运行环境。
- 用户对目标 Base 的最小必要读取和写入权限。
- 录入订单、发票、截图或表格时，由用户提供相应材料并确认可使用范围。

## 初始化

优先接管现有 Base：在运行时提供入口后，先读取数据表、字段、公式字段和状态选项，再查重和写入。没有现有 Base 时，只有在用户明确要求后才新建；创建前先确认字段方案，创建后写入少量虚构示例或首批已确认数据并回读。

`examples/` 中的数据明确为虚构，`templates/` 只描述通用字段结构，不能直接替代目标 Base 的真实字段读取。

## 隐私边界

飞书入口及其凭据、数据表和记录标识、账号与本地配置仅作为运行时信息，不得硬编码或提交。不要保存与资产管理无关的个人联系方式、收货信息、完整交易凭证或登录信息；面向用户的摘要只展示必要的可读结果。删除记录、数据表或 Base 前必须再次确认。
