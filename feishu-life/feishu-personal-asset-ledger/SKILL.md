# Feishu Personal Asset Ledger

使用飞书多维表格建立、迁移和持续维护个人或家庭资产台账。

## 适用场景

- 从购物订单、发票、截图或 Excel 录入资产；
- 记录数码、家电、车辆、房产、家具和其他耐用品；
- 跟踪购买金额、启用时间、保修、使用状态、退役和出售；
- 计算使用天数、日均成本和处置后的实际成本；
- 创建或优化资产总额、分类、状态和成本仪表盘；
- 将装修、搬家或采购项目中的设备同步到资产台账。

不适用于流水账、日常耗材或投资证券组合；这些数据应使用独立台账。

## 依赖与定位

优先使用飞书 Base / 多维表格能力。用户提供 Base URL 时先解析真实 Base token，并实时读取表、字段、记录、仪表盘及图表组件；用户没有现有 Base 且明确要求新建时，才创建新 Base。

Base URL、token、table ID、record ID、dashboard ID、block ID、账号和本地路径都属于运行时配置，不得硬编码到 Skill、模板或示例中。

## 推荐字段

- `资产名称`：文本，主字段；
- `分类`：单选；
- `资产金额`：货币；
- `购入时间`：日期；
- `购入来源`：文本；
- `归属人`：文本或人员；
- `使用状态`：单选，建议包含`已购买待启用`、`使用中`、`已退役`；
- `保修到期时间`、`退役时间`：日期；
- `出售价格`：货币；
- `整机配置`、`资料来源`、`备注`：文本；
- `使用天数`：公式；
- `日均成本`：公式；
- `更新时间`：系统更新时间。

字段应按用户实际需求创建；写入前读取真实字段类型和单选选项，不猜字段 ID。

## 核心原则

1. **现有 Base 是主数据。** 先读真实结构和同名记录，再决定更新或创建。
2. **一项资产一条记录。** 使用名称、型号、来源和购买日期组合查重；多候选时先消歧。
3. **真实成交价优先。** 订单实付或发票 > 已确认结算价 > 用户确认价 > 预算或暂估。
4. **预算不能冒充实付。** 暂估和预算必须在备注中明确标记。
5. **公式字段只读。** 使用天数、日均成本、更新时间等公式或系统字段不得作为普通记录值写入。
6. **事实不足不猜。** 型号、代际、保修、日期或折扣拆分不明确时保留待确认项。
7. **图表口径透明。** 指标卡、饼图和柱状图必须在名称中区分金额、数量、平均值和筛选范围。
8. **隐私最小化。** 不保存手机号、地址、完整订单号、验证码、Cookie、token 或无关个人信息。
9. **写后回读。** 记录写入后按 record ID 回读；图表创建或更新后读取计算结果，核对维度、聚合和筛选。
10. **删除需确认。** 删除记录、表、仪表盘、图表组件或 Base 前列出准确目标并获得明确授权。

## 标准流程

### 1. 初始化或接管现有台账

1. 解析用户提供的 Base URL；
2. 列出数据表、字段、视图、仪表盘和组件；
3. 识别主表、公式字段、状态选项和已有统计口径；
4. 如果需要创建新表，先展示字段方案；
5. 创建后写入少量示例或用户首批数据并回读验证。

### 2. 从订单或截图录入

提取资产名称、型号、实际支付金额、购买日期、平台/店铺、归属、使用状态和资料来源。

- 详情页优先于总览页；
- 同单多商品存在整单优惠时，可按商品行金额比例分摊，但必须记录算法；
- 无法可靠拆分时保留订单总额或待确认项，不伪造单品价格；
- 不录入截图中的手机号、地址、订单号等隐私字段。

### 3. 整机与组合资产

用户要求记录电脑、家庭服务器或组合设备时，默认每台最终整机一条记录。

- 展开 Excel 公式、数量乘法和额外费用；
- `整机配置`记录主要配件、数量和价格；
- `资料来源`记录文件名或工作表；
- 用户明确要求配件级管理时，再建立独立配件明细表。

### 4. 状态与成本

建议公式逻辑：

- 使用中：购入/启用时间到今天，首尾日期均计入；
- 已退役：购入/启用时间到退役时间；
- 日均成本：`(资产金额 - 出售价格) / 使用天数`；
- 日期或金额缺失时返回空值或0，避免除零错误。

只有用户或来源明确确认已经投入使用、退役或出售时才能改变状态。

### 5. 资产仪表盘与图表

优化前先读取已有仪表盘、组件名称、类型、`data_config` 和计算结果；优先更新已有组件，不重复创建同口径图表。推荐最小组合：

- 指标卡：资产总额、资产数量、待启用资产数；
- 饼图或环形图：使用状态分布，按记录数量统计；
- 分类金额图：按分类汇总资产金额；
- 条形图：使用中资产按分类计算平均日均成本。

图表规则：

- 指标名称明确写出“金额”“数量”“平均值”等口径；
- 如果房产、车辆等单一类别占比过大，导致其他类别在饼图或成本图中不可读，保留全量总额指标卡，同时增加或改用明确标注的“非房产”“非主要类别”图表；不得偷偷改变口径；
- 单选字段排除某类别时使用平台真实支持的筛选操作符，并在更新后读取计算结果，确认不是只保留了一个选项；
- 组件在同一仪表盘内串行创建，避免并发写冲突；
- 只有用户要求优化、美化或重排时才调用智能布局；布局后再次读取仪表盘组件清单；
- 不为同一统计口径同时堆叠多个无意义的图表类型。

### 6. 与采购项目联动

当资产来自装修、搬家或集中采购项目时：

- 项目台账负责预算、付款、送货、安装、验收和结算；
- 资产台账负责成交金额、归属、启用、保修、使用成本和退役；
- 已购买未启用映射为`已购买待启用`；
- 实际投入使用后映射为`使用中`；
- 项目预算不得覆盖更可靠的订单实付金额。

## 验证清单

- 使用的是用户当前指定的 Base；
- 读取了真实字段、状态选项和已有仪表盘；
- 没有重复创建资产或同口径图表；
- 没有写入公式、系统或附件只读字段；
- 金额、日期、状态和图表筛选均有来源；
- 图表名称清楚区分金额、数量、平均值和排除范围；
- 图表计算结果已回读，维度和数值符合预期；
- 没有写入不必要的隐私信息；
- 写后回读成功，分页范围清晰；
- 回复只展示用户可读摘要，不暴露内部 token、record ID、dashboard ID 或 block ID。
