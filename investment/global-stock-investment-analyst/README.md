# 全球股票投资分析助手

这是原“A股银行股分析与做T助手”的扩展重命名版本。现在使用一个 Skill 统一分析A股、港股、美股、中概股、ETF和REITs，不再维护单独的银行股分析入口；原有银行专项与A股做T能力完整保留。

## 安装

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/investment/global-stock-investment-analyst
```

## 通用能力

- 区分盘中、盘前、盘后与正式收盘行情。
- 计算MA、阶段收益、RSI、MACD、波动率、最大回撤和相对成交量。
- 分析财务质量、现金流、估值、公司公告、SEC文件和未来催化剂。
- 结合利率、汇率、商品、监管和地缘因素分析影响路径。
- 根据持仓成本、币种、费用和风险承受能力给悲观、基准、乐观三种情景。

## 保留的银行股与做T能力

- 净息差、不良率、拨备覆盖率、核心一级资本充足率、PB、ROE和分红。
- 资本债、无固定期限资本债、总损失吸收能力债券及利率环境。
- A股T+1、可用底仓、最低佣金、卖出印花税、过户费和其他费用。
- 计算做T保本价差、预计净收益以及只成交一边的处理方案。

## 行情脚本

`global_market_snapshot.py`：

- A股、港股使用腾讯公开行情与K线接口；
- 美股和美国ETF使用Nasdaq公开info与historical接口；
- 支持示例：`AAPL`、`QQQ`、`600519.SS`、`601939.SS`、`000001.SZ`、`0700.HK`。

```bash
python3 scripts/global_market_snapshot.py AAPL QQQ 601939.SS 0700.HK   | python3 scripts/technical_summary.py
```

公开接口可能延迟、限流或变更，运行时必须核验时间、时区、币种、交易状态及复权口径。

## 边界

不连接券商，不自动交易，不承诺收益，不保存私人持仓、成本、飞书入口、券商账户或登录凭据。

仅作持仓记录与信息分析，不构成投资建议。
