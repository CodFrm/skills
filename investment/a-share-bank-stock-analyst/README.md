# A股银行股分析与做T助手

获取A股银行股的盘中行情、前复权日K、技术指标、估值、分红和交易所公告，并结合用户真实佣金、印花税、过户费及持仓数量生成费用敏感的做T方案。

## 安装

```text
帮我安装这个 Skill：https://github.com/CodFrm/skills/tree/main/investment/a-share-bank-stock-analyst
```

## 主要能力

- 查询盘中价格、开高低、成交量、成交额、量比、换手率、PE和PB。
- 计算MA5/10/20/60、RSI14、MACD、ATR和阶段涨跌幅。
- 读取交易所公告、分红实施公告和银行股资本补充信息。
- 综合均线、近期高低点、成交量和波动率划分观察支撑与压力区。
- 按真实双边费用计算做T保本价差、预计净收益和只成交一边的风险。
- 支持先卖后买、先买后卖和观望三类方案，但不自动下单。

## 附带脚本

`scripts/tencent_kline_snapshot.py` 使用公开的腾讯行情接口读取行情和前复权日K。公开接口可能延迟、限流或变更；运行时应核验时间并准备备用数据源。

```bash
python3 scripts/tencent_kline_snapshot.py 601939 601398
```

## 风险提示

- A股股票实行T+1，当日新买股份不能当日卖出。
- 最低佣金会显著侵蚀100股或200股的小额做T收益。
- 技术支撑和压力只是观察区间，不是保证。
- 不保存账户、股东号、验证码、Cookie、资金密码或私钥。

仅作持仓记录与信息分析，不构成投资建议。
